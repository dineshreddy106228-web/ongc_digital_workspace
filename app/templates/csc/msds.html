How slots work

Each material carries one ONGC standard sheet plus up to three vendor-submitted sheets. Uploading to a slot that already holds a file replaces that file and leaves the other slots untouched.

Storage

PDF bytes and their metadata are stored in the database, so sheets travel with backups and stay available to every module that links here.
